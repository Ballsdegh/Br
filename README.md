# FUCKBR Viewer

Веб-версия FUCKBR GUI, переделанная под нормальный workflow просмотра моделей:

1. Загружаешь архив текстур (ZIP или пачка `.png`/`.btx`/`.ktx`).
2. Загружаешь модели (ZIP или пачка `.dff`/`.mod`; `.mod` автоматически
   расшифровывается в `.dff`).
3. Получаешь список моделей. Имена подтягиваются из `data/peds.txt`
   (стандартный `peds.ide`), если модель там есть.
4. Кликаешь модель — справа сразу видно, какие текстуры она возьмёт
   (найдены / отсутствуют в архиве), и рендерится превью.
5. Крутишь мышкой/пальцем — модель вращается (каждый кадр — новый рендер
   на сервере, дебounced во время перетаскивания, полное качество после
   отпускания).

Старые пакетные конвертеры (BTX↔PNG, MOD→DFF, ANI→IFP, CLS→COL, BPC→ZIP)
остались на `/tools` — тот же workflow, что и в оригинальном GUI 2.2
(загрузил файлы/ZIP → скачал `FUCKBR_result.zip`).

## Структура

```
app.py                 Flask-приложение (роуты /, /tools, /api/...)
wsgi.py                точка входа для gunicorn
engine/                вся "движковая" логика (парсер DFF, рендер, тексты)
  dff_parser.py         разбор RenderWare DFF (без изменений по сути)
  render.py             CPU-рендер (numpy), тот же алгоритм, что и раньше
  mod.py                расшифровка .mod → .dff (TEA)
  textures.py           BTX/KTX → PNG через бандл kram+PVRTexToolCLI
  peds.py               парсинг peds.txt для красивых названий моделей
  session.py            сессии: загрузка, список моделей, кэш рендеров
  kram/, pvr/            бинарники для декода текстур (linux/win)
data/peds.txt          твой файл, используется для сопоставления имён
templates/, static/    HTML/CSS/JS фронтенда
sessions/              runtime-данные (создаётся автоматически, не коммить)
android_aide/          проект для AIDE — обёртка-приложение под Android
```

## Запуск

```bash
pip install -r requirements.txt
python3 app.py
```

Открой `http://127.0.0.1:8765`.

Про деплой на хостинг/VPS — см. `README_HOSTING.md`.
Про мобильное приложение (AIDE) — см. `android_aide/README.md`.
